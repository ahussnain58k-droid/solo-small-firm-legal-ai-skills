# Start Here

This repository is designed for solo lawyers and small legal teams.

## You do not need coding

Begin with one of these tasks:

- Need to explain contract redlines? Open `skills/redline-emailer/`.
- Need an AI-safety check? Open `skills/privilege-sentinel-ai-safety-check/`.
- Need a reusable contract template? Open `skills/contract-template-synthesizer/`.
- Need startup formation support? Open `skills/startup-formation-counsel/`.
- Need Texas title analysis? Open `skills/texas-title-analysis/`.

## Before using any skill

1. Remove unnecessary client-identifying information.
2. Confirm the correct jurisdiction.
3. Check current law and professional rules.
4. Treat AI output as a draft.
5. Obtain qualified lawyer review.
